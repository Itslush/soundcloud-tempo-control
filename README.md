# SoundCloud Track Control has moved

Main project: https://github.com/Itslush/soundcloud-track-control

Website: https://itslush.github.io/soundcloud-track-control/

This compatibility repository keeps old website links and userscript update URLs working. Redirects preserve track settings in query strings and fragments. After upgrading, installed scripts check the new website for updates.

The compatibility files are generated with `scripts/build-compatibility.cjs` in the main repository. Do not install both copies of the script.
