# SoundCloud Tempo Control

An unofficial SoundCloud userscript and its download website, built for listeners who want speed control, natural pitch changes, optional key preservation and per-track tempo memory.

The userscript extends SoundCloud's existing footer. A centered settings panel holds saved tracks, sharing preferences and advanced audio. The timeline editor supports nodes, fades, zooming and shareable tempo links.

The Astro website offers installation, a working audio preview, real interface captures, release notes and optional donations. Its small Node backend resolves public tracks through a pinned yt-dlp installation without API credentials. Local files stay in the browser. The default demo is Drown (Sewerslvt Remix), loaded only after Play is pressed.

Keep the existing orange cloud, waveform and slider logo, with sparse stars as a background accent. Keep controls compact and text direct. Avoid claims about perfect sound, negligible processing cost or universal compatibility. All features remain free.

The repository targets a userscript release first. A browser extension is a separate packaging step that must bundle executable dependencies locally.
