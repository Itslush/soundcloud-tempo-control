# Assets

- The project logo is the approved orange cloud, waveform and slider artwork in `site/public/`.
- `site/public/screenshots/*.png` are browser captures from public SoundCloud tracks. `screenshot-evidence.json` records URLs, actions, dimensions and media state. They use early userscript injection in an isolated, muted Chrome session, not a Violentmonkey installation.
- All eleven captures were refreshed on 2026-09-06 from the exact 480,040-byte userscript with SHA256 `789a8430f052ed86b1bc3c096a19f3cb5c98b653e8a3aae66fe42849d68355cb`. The evidence records the capture script, output probe and image hashes, UI actions, real media readiness and closed muted contexts. PNGs carry neutral UTF-8 Source metadata; their screenshot pixels are unchanged. Refresh the set with `python tests/capture-showcase.py --expected-artifact <sha256>` when controls change.
- The public music shown throughout is the explicitly selected [Bring Me The Horizon - Drown (Sewerslvt Remix)](https://soundcloud.com/sewerslvt/bring-me-the-horizon-drown-sewerslvt-remix). Its 0.90× speed and three-point timeline were saved through the real UI; the library shows one genuine track with both settings. Shared-preview captures use the actual copied link in a fresh receiving context before applying or saving it. No song names, library entries or interface pixels were fabricated. The music is not bundled with these images. The website's default track loads only after Play; the synthesized sample remains an explicit fallback.
- Desktop captures use a 1440-pixel viewport and narrow variants use a 390-pixel desktop-browser viewport, both at 3× device scale. These do not establish physical-mobile or installed-userscript-manager coverage. Browser mute, native zero volume and a permanent final zero-gain output prevent audible playback during capture.
