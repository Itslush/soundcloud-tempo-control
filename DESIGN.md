# Design

## Identity

Preserve the charcoal SoundCloud-style surface, orange cloud/waveform/slider logo, small corner radii and flat controls. The website uses locally hosted Mulish. The userscript inherits the player's font and foreground colour.

Use orange `#ff5500` for interaction accents, selected nodes and playback. On SoundCloud, read the progress bar's current accent so themes remain consistent. Tempo and playback rails use the same 2 px thickness and centerline. Ticks sit below the tempo rail without shifting it.

Tempo rulers use one SVG coordinate grid with evenly spaced tick centers spanning the thumb's center-to-center travel. Keep stroke widths constant as the control resizes. The userscript marks every 0.025× stop, with longer 0.05× and 0.25× marks. All range controls use a 2 px rail and a 12 px outlined circular thumb. The rail, fill and tick centers share the same 6 px inset. Footer horizontal thumbs appear on hover, keyboard focus or dragging; settings, star-speed and vertical thumbs stay visible so their current values are apparent before interaction. All thumbs stay visible on touch-capable devices and in forced colours. Only opacity changes, never thumb size or travel. Programmatic value changes update the fill too. Graph nodes remain visible.

Playback speed spans 0.25× to 4×; the horizontal slider stops at 2× while the exact number field, dial and vertical fader cover the full range. Appearance offers a horizontal Slider, Dial or Vertical slider without changing the compact native footer. The dial uses a 270-degree logarithmic scale with 1× at twelve o'clock, 17 ticks and longer marks at 0.25×, 0.5×, 1×, 2× and 4×. Vertical dragging doubles or halves speed over 160 px, with five-times finer Shift-drag; reversing at a limit responds immediately. Persist the style choice locally and synchronize it across tabs. On the first clean SoundCloud visit without a saved control style, focus the chooser inside the existing settings dialog and offer the semitone visibility toggle alongside it. Use this style confirms and persists the displayed choice, including the default Slider. Keep both choices available afterward in Appearance. Incoming shared tempo links open the editor first so the first-run chooser does not compete with it.

Appearance offers Show semitone adjustment in player, on by default. Hiding it reclaims the footer space in every control style without resetting the semitone shift. Advanced audio and the editor retain pitch access. Persist this preference across reloads, tabs and backups. Default tempo increment starts at 0.025× and accepts 0.001× to 1×. It controls tempo arrows and keyboard stepping in the player and editor; pointer dragging and direct typing retain finer control.

Advanced audio offers opt-in Crossfade tracks with a 1–10 second overlap (5 seconds initially). Prepare the identified outgoing AAC stream's tail and the next queue item's opening, including its saved tempo and pitch processing. Start both buffered sources on one audio clock, retain the outgoing processor's history, and advance SoundCloud's own Next control once. The native next player stays muted until its audible position matches the buffered opening within 20 ms, then takes over through an 80 ms blend. The opening includes up to eight extra seconds for synchronization; expiry restores native playback with a diagnostic warning. Crossfade never guesses a stream or reorders the queue, and leaves unsupported streams and incoming tempo timelines playing normally with an explanatory status. Native volume, mute and output gain apply to both tracks. Manual transport changes cancel the overlap. Silent browser captures exercise delayed native startup and the handoff; live-account behavior is not claimed by those fixtures.

Timeline close zoom uses rounded bounds and a 0.1× grid; closer zoom uses 0.05×. Do not generate axis labels by evenly dividing arbitrary bounds. Retain all gridlines, prioritize the floor label and suppress adjacent labels that would overlap it. Min and Max stay visible together beside Speed range; valid bounds (0.25× ≤ Min < Max ≤ 4×) select Custom and frame only the graph, staying fixed through point selection and editor reopening in the current tab until a preset or Fit resets them. The website demo defaults to the explicitly selected Drown (Sewerslvt Remix). Do not add other personal listening references.

Website tokens live in `site/src/styles/site.css`. Controls use a distinguishable border rather than relying only on colour or hover. Focus remains visible in keyboard navigation and forced-colour modes.

## Website

The opening pairs a short introduction and installation action with an interactive timeline. Playback controls appear before the graph. Playback is explicitly started by the visitor at a low initial volume. The graph, time readout, seek control and tempo value reflect actual audio state.

Fixed speed and Timeline are explicit modes. Keep the current playback rate separate from the selected point's target. Original comparison is temporary and preserves both the listening position and edits. Editing offers undo, redo and reset without adding controls to the SoundCloud header.

Custom pitch menus visibly identify Pitch, expose the selected value, support keyboard navigation and close on Escape or outside interaction. Closed choices are inert. Point timing and track loading are secondary disclosures. The native select remains available without JavaScript.

Pitch shift is a fractional control from −12 to +12 semitones in Advanced audio, the timeline editor and the website preview. Keep its label and units explicit. It composes with Natural or Preserve key through the existing Signalsmith processor and travels with shared timelines. The footer keeps Pitch, a typed semitone field, st and custom increment/decrement arrows on one line with a 16 px margin separating this group from tempo. Steps default to 0.5 st and can be changed, along with the bounds, in Semitone controls. Each bound and the default increment gets its own aligned row. Musical-key mode is removed; old preferences retain their semitone bounds and increment, and saved pitch automation remains intact. Custom choices retain listbox keyboard navigation and visible focus. Dial and vertical styles use a compact fixed-width group. The vertical style opens a 144 px fader above the entire footer, with a centred live value, quarter-speed ticks, labels at 0.25×, 1×, 2×, 3× and 4×, and Reset. It stays closed at rest, keeps its thumb visible, and dismisses with Escape or an outside click. At 960 px and below, the footer wraps without increasing the controls' 32 px height.

Number fields share SVG minus/plus buttons with 44 px targets, tabular centered values, direct typing and keyboard stepping. Native number spinners are hidden. Point timing uses 0.1-second steps and speed uses the saved default tempo increment. Button limits follow the selected point.

The brand and navigation form a full-width sticky header with an opaque surface and a single bottom divider. Anchor destinations clear the header. The introduction stays top-aligned when the editor expands. Desktop copy remains sticky below the header; mobile copy returns to normal flow.

A sparse SVG starfield spans the page behind opaque text and control surfaces. Its drift translates from (−40 px, −30 px) to (40 px, 30 px) over 7.5 seconds with linear timing, alternating directions. Pause it when hidden and remove animation when reduced motion is requested. Vary small rays, diamonds and paired stars, with subtle warm and cool tones. Do not use glow, haze or blur. Keep cards opaque and the orange accent unchanged. Stars ignore pointer input and disappear in forced-colour mode.

The default track loads only after Play is pressed, at the existing low volume. Failed loading offers an explicit synth fallback. Do not silently substitute audio or fetch the default song on page load.

Real screenshots appear in four focused sections with full-resolution viewers. Use the explicitly selected Drown track for public examples, including its saved speed and timeline. Keep captures proportional. Reserve their space while loading, show a restrained skeleton, and provide a retry path if loading fails. Never redraw screenshots as if they were live product evidence.

Layouts stack on narrow screens. Long track titles truncate without covering transport controls. Website controls, graph hit regions and secondary navigation links have at least 44 px targets. Graph handles capture dragging while the rest of the graph permits vertical page scrolling. The compact SoundCloud footer retains the host client's density.

The userscript settings contain the saved-tempo library and backup controls. Apply saved tempos is an explicit checkbox, enabled by default; do not offer random 50/50 application. Use compact single-line rows with a track link, enabled checkbox, speed or Timeline control and removal button. Keep both settings together when a track has both. Preserve full accessible names and removal undo without repeating visible On/Off labels. The bounded list scrolls separately from search and the collapsed audio, shortcuts and backup sections. Import replacement is previewed and confirmed before changing storage.

Retain the same orange rather than introducing a second accent for text. Selected website modes use dark backgrounds. The footer speed value and × share the inherited foreground without a changed-value background. Right-align the number in its fixed slot with a 2 px gap before the unit. Native primary text controls retain `#242424`, with `#282828` on hover, including the light player theme.

SoundCloud appearance is optional: SoundCloud preserves the host theme, Charcoal uses the homepage's `#111` ground and `#202020` panels, and OLED uses `#000` and `#0b0b0b`. The custom themes share the existing orange, muted text and sparse starfield, with a linear alternating background-position drift from (0, 0) to (96 px, 72 px). Star speed is adjustable from 0.5× to 4× against a 15-second base; default 2× takes 7.5 seconds. Pause the drift when hidden. Keep foreground panels opaque and stars free of glow. Keep host layout, artwork, waveforms and interaction behavior intact. Apply scoped semantic colour tokens rather than global image filters or hashed component selectors. Validated same-origin track frames follow the preference; authentication and third-party frames do not. Returning to SoundCloud removes owned styles and restores owned attributes. These settings are local and synchronize across tabs; a failed save reports that it applied only to the current tab.

## Copy and motion

Track changes fade the footer artwork and artist/title together from 25% to full opacity over 240 ms. Leave transport and action buttons unchanged, cancel interrupted fades, and switch immediately with reduced motion. Audio crossfade has a collapsed diagnostics disclosure in Advanced audio: current buffer/readiness values, handoff timing error, remaining opening audio, a bounded local event history, Refresh, and Copy diagnostics. Reports exclude track URLs and account data and are never uploaded automatically. Readiness follows the next track's saved speed rather than always assuming 4×.

Advanced audio pairs Output level with an editable dB field and a −24 to +12 dB slider. Typed boosts have no product ceiling; reject non-finite values and gains beyond Web Audio's numeric range. Expand the slider to include a typed boost. Keep the default −6 dB, preserve SoundCloud's own volume and mute, and warn that positive gain can clip. Boost reuses the existing player audio graph; report when that connection is unavailable.

Use short functional labels and neutral statements. Do not add routine selection hints, mode narration, screenshot captions or instructions that repeat visible controls. Preserve accessible names and nonvisual keyboard guidance. Show status text only when it communicates useful loading, success or error feedback. Avoid sales claims, em dashes and long hover descriptions. Error text explains the next useful action. Donations stay optional and do not gate functionality.

Website copy names the action or behavior without forced familiarity, invented author anecdotes or phrases such as "tip jar". Donations use one collapsed disclosure before the footer, not a separate support page. The five requested currencies show their full addresses and networks with the existing outlined Copy address button. ETH and USDT use Ethereum mainnet, with ERC-20 explicit for USDT. Addresses wrap on narrow screens and remain selectable without JavaScript. Copy success and failure stay beside their own address. No wallet connection or payment embed is involved.

Shared motion tokens use 120 ms for quick feedback, 200 ms for entrances and 100 ms for exits. Menus, supported native disclosures and image viewers reverse cleanly during repeated interaction. Skeletons pulse gently. Reduced motion removes spatial movement and pulsing while retaining immediate state changes and focus visibility. SoundCloud Appearance offers a two-state Star motion checkbox and a speed slider, disabled while motion is off. Until the user chooses, initialize the toggle from reduced-motion preferences; old Follow system values retain that behavior without a third UI choice. Explicit On overrides reduced motion only for the starfield, and hidden tabs still pause it. Do not animate inactive playback or redraw the graph for every playhead update.

## Pitch automation and shared controls

Design read: a compact music tool within SoundCloud, not a marketing dashboard. Keep the charcoal/orange identity, Mulish on the website, inherited player typography, small radii and flat controls. Dial: ENERGY 1 / RHYTHM 2 / MOTION 2. The graph is the editor's focal point; spacing separates transport, editing and sharing. Orange indicates the curve and active controls. Stars are the user's requested background motif, not feature icons; no glow or extra decoration is needed.

Tempo and Pitch are independent graph lanes using the same points, fade timing, curve choices, mouse dragging and keyboard controls. Start the tempo view at 0.75–1.5×. Pitch supports −12 to +12 st, fractional typed values and customizable arrow steps. Saving, applying once, importing, exporting and sharing retain both lanes. A manual player pitch change overrides the running pitch curve; saving afterward replaces that curve with the explicit value. Show this as an unsaved change rather than silently rewriting the saved profile.

The website embeds the real editor rather than maintaining a second approximation. Fixed controls are hidden in Timeline mode, where the editor owns pitch and tempo. Copy links lead to the existing website's share page, which validates the embedded data and offers installation, adjusted playback or the original SoundCloud track. A separate custom hostname requires DNS and is not configured by the source.

Website and plugin star speed use a 15-second base divided by the chosen 0.5–4× speed; default 2× gives 7.5 seconds. Both have an on/off toggle. Start from reduced-motion preferences until a user explicitly chooses; explicit On affects only stars. Disable the speed field when motion is off. Keep stars behind opaque content.

No generated imagery, promotional claims, testimonials, counters, new icon library or additional content sections are part of this change. Shadows are limited to floating menus. Arrows operate numeric controls or disclose choices; they are not decorative calls to action.

Settings choices keep a visible border, padding and an SVG disclosure arrow, so the closed control still reads as interactive. The compact key group orders label, value, unit and arrows; the arrows have the same width as the tempo arrows. Its fixed number slot accommodates fractional negative values without pushing neighboring actions. The vertical popover is 96 px wide, keeps its 144 px rail, and places endpoint and 1× labels to the left of the thumb's travel. Reset has a visible button boundary. Thumb outlines mix the accent with 15% foreground to remain distinguishable on both light and dark player backgrounds.
