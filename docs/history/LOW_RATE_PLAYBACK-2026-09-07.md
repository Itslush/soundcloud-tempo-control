## Implemented path

- `source-binding.mjs` links an observed media element's blob URL to its MediaSource, SourceBuffer and matching MP4 payload hashes. Prefetch order and footer text are not source identity. Ambiguous matches remain unbound. Media observation is weak; passive source/load hooks do not register unselected media.
- `bounded-source.mjs` uses checksum-pinned Mediabunny 1.55.7 and WebCodecs to decode bounded AAC-LC reads. It validates host, byte, queue, timestamp and coverage limits. Four-packet bounded preroll addresses the measured AAC seek transient. Other codecs are rejected.
- `pcm-window.mjs` keeps a shared-budget read-ahead cache and returns absolute-frame PCM leases. Decoded packet counts establish continuity and verified EOF; metadata duration is only a hint.
- `rate-clock.mjs` carries source/output frame mappings using the actual Float32 rate. `buffered-transport.mjs` serializes commands, stops polling while idle, and freezes source position during buffering.
- `natural-output.mjs` schedules native buffer sources with neighboring PCM and muted preroll. `preserve-output.mjs` and `preserve-worklet.mjs` use the pinned Signalsmith compiled engine through a bounded project-owned processor.
- `playback-owner.mjs`, `media-facade.mjs` and `playback-gate.mjs` coordinate play, pause, seeks, source replacement and graph ownership. Native and buffered routes do not play together. Logical volume, mute and global output dB reach the buffered route once.
- Owned rate getters report the full-precision requested tempo, including while paused or buffering. Coalesced `ratechange` events remain separate from the renderer's scheduled/quantized rate.
- `tempo-buffered.js` connects these modules to userscript settings and source discovery. Dependencies and decoding are deferred until needed; ordinary native playback does not allocate the buffered route.
- `soundcloud-host-clock.mjs` validates already-loaded SDK methods, exact current queue ownership and media identity before binding `host-clock.mjs`. Owned host reads use the buffered source clock and decoded duration. Native handback and descriptor restoration are coordinated; unknown host implementations stop the requested low-rate route safely.

The encoded-resource ceiling is 16 MiB per source transaction, including assembly overlap, with 4 MiB per resource and 2 MiB of copied decoded PCM. The PCM cache has an 8 MiB combined ceiling. Natural output allows at most 32 MiB of owned AudioBuffers and 16 source/gain nodes; Preserve output limits owned PCM to 8 MiB. These are separate ceilings, not normal consumption or a bound on opaque browser/native allocations.

The decoder bundle is fetched unchanged and checksum-verified. Its license and versioned source link are in [vendor/mediabunny](../../vendor/mediabunny/NOTICE.md). The existing Signalsmith vendor file remains unchanged. An independently reproduced cursor bug in its upstream buffered wrapper is covered by `verify-buffered-cursor.cjs`; the project-owned Preserve processor does not adopt that faulty loop.

The host integration must guard every active player layer, not only the media-owning leaf. Each proxy has its own state manager and independently infers completion from position equality; it does not simply inherit the leaf's ended state. Clock and duration correction are separate requirements. The leaf must read the owned source clock, propagate real duration through its state manager and preserve host-assigned duration when ownership ends. Its HLS-specific stalled-near-end heuristic must not override actual buffered completion. Discovery must validate the already-loaded host implementation and stop a requested low-rate route safely when that implementation is unknown. The integration below handles these requirements. Deterministic tests cover inaccurate duration hints, replacement during synchronization, native handback and conflicting descriptor restoration; live repeat and broader error-recovery acceptance remain open.

## Reproduction

Prepare the pinned diagnostic decoder once, then run every audio module and integration-adapter unit suite:

```sh
npm run setup:decoder-probe
npm run test:audio-candidate
```

CI performs the same setup before the unit command. It does not use live SoundCloud as a unit-test dependency.

Run the isolated host-clock checks separately:

```sh
node --test tests/host-clock.test.mjs
python tests/test-transition-completion.py
python tests/verify-host-clock.py
python tests/verify-host-clock-candidate.py --mode natural
python tests/verify-host-clock-candidate.py --mode preserve
```

The last three commands require live SoundCloud. Candidate runs verify observed host-method fingerprints before attaching the unbundled adapter and write uniquely named reports. They do not install or rebuild the public userscript.

Run the generated ownership integration separately:

```sh
python tests/verify-playback-owner.py
```

The public-source diagnostics require network access:

